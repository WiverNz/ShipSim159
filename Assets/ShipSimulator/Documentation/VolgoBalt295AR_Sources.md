# Volgo-Balt Project 2-95A/R: Sources and Data Status

This file separates published particulars from prototype estimates for the Volgo-Balt vessel in
`VolgoBalt295AR.json`. Individual ships differ after conversions; the data describes an unconverted
2-95A/R in loaded river condition. Nothing here is validated for maritime training.

## Why project 2-95A/R

"Volgo-Balt" covers projects 791 (Krasnoye Sormovo, from 1962), 2-95, 2-95A and 2-95A/R (Slovenské
lodenice, Komárno). More than 200 ships of the type were built in total. Project 2-95A/R is the
largest single series found: 79 ships built from 1973 to 1984, against about 65 of project 2-95A
(1969 to 1972). Counts come from FleetPhoto project pages and search summaries of Russian river-fleet
sources; they are approximate.
