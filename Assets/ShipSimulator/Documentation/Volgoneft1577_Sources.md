# Volgoneft Project 1577: Sources and Data Status

This file separates published particulars from prototype estimates for the Volgoneft tanker in
`Volgoneft1577.json`. Individual ships differ after conversions; the data describes an unconverted
project 1577 tanker in loaded river condition. Nothing here is validated for maritime training.

## Why project 1577

The Volgoneft type covers projects 558 and 550 (about 80 built, 1962 to 1971), the modernised 1577
(USSR) and its Bulgarian twin 550A, and project 630. Russian Wikipedia gives about 70 ships of
project 1577 built in the USSR (1967 to 1979) and about 65 of project 550A in Bulgaria (1969 to 1982),
the largest group. In 2013 the Russian River Register listed 110 tankers of 1577/550A against 21 of
558/550. Counts are approximate.
